Privacy in your pocket.

HEYMI Pocket Beta is designed as a local-first companion game. This notice explains what the current web beta stores and what remains under your control. Last updated July 15, 2026.

Game data stored locally

The app stores your chosen keeper and companion names, appearance, care statistics, inventory, activities, garden, collections, accessibility settings, and onboarding status in this browser's local storage. There is currently no HEYMI account or cloud synchronization.

No advertising or tracking scripts

The beta contains no advertising SDK, behavioral analytics, social tracker, or third-party script. The company that hosts the static website may still process ordinary technical access logs, such as an IP address, request time, and browser information, under that host's own policies.

Backups

An exported backup is an unencrypted JSON file containing game data and the names you chose. It does not include a Desktop Link bearer token, PC address, or saved device identity. Anyone with the backup file may be able to read its contents, so store it somewhere private.

Desktop Link

The public web beta does not expose Desktop Link. When the full edition is served privately by HEYMI Desktop or installed as the native edition, optional pairing credentials can be stored locally and approved remote commands are sent only to the paired desktop endpoint.

Retention and deletion

  • Use Export backup before changing devices, browsers, or app addresses.
  • Use Reset game progress to restart the companion game while retaining accessibility and optional Desktop Link settings.
  • Use Erase all HEYMI data to remove local game data, settings, link credentials, and HEYMI Pocket caches from this browser.

Browser storage may also be removed by private-browsing restrictions, device storage pressure, browser settings, or clearing website data.
