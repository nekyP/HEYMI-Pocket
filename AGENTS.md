# HEYMI Pocket source guidance

Preserve the installable static PWA, device-local state, accessibility and
existing explicit private-network desktop pairing. The public website does not
gain desktop authority, Node/Git execution, provider keys or remote control from
a developer-tool manifest. Keep credentials, pairing tokens and private desktop
state out of public source, reports and service-worker caches.

Shared source-compute commands are local Node.js 24+ developer tooling only.
Use explicit tracked source scopes; never ingest browser profiles, localStorage
dumps, user data or desktop authentication tokens. Reports and static checks do
not execute proposed code or authorize application state changes.

When changing shipped PWA files, preserve offline/cache compatibility and verify
the relevant browser/device behavior. Source-tool checks do not establish a
published site, an installed PWA update or a paired desktop connection.
